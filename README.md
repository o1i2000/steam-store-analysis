# Steam Store Game Analysis

A data analysis project identifying market opportunities for game development on Steam, based on ~140,000 games across categories, genres, pricing, and release timing.

## Key Findings

- **Best category**: Deckbuilding, Base Building, and Roguelike hybrids with Cinematic or Co-op elements
- **Optimal price**: $15–30 mid-tier or $30+ premium; avoid <$5 budget
- **Best release**: November–December; avoid February and August
- **Biggest success factor**: Releasing a playable demo (+0.40 correlation)
- **Top market gap**: Action Roguelike + Cinematic (74 games, high success)

## Files

- `Steam Store Analysis Project .ipynb` — Main analysis notebook
- `Steam Store Analysis Project _executed.ipynb` — Executed copy with all outputs cached
- `AGENTS.md` — Agent workflow documentation

## Data Sources

SteamSpy, Steam Store API, and Steam Community API. Raw CSV data is excluded from this repository due to file size (>50MB).

## Tools Used

Python (pandas, numpy, matplotlib, seaborn, plotly)
